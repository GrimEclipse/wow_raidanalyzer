Offline Package

WoW Raid Analyzer

无需 Python。构建时已内嵌复盘 JSON，打开报告页即可自动加载。

Report

主报告 / 开庭分析

自动读取内嵌 wcl_hardcore_api 数据，查看玩家计数、不计数与逐场证据。

Final Verdict

终审判决历史

日期翻页、叠加导入、申诉备注和配置导出。

Fight Audit

逐场场地分析

按 Fight、阶段和 Tag 定位场地快照。

用法：双击 start_offline.bat 或本页进入报告。数据在打包时烘焙到 assets/vendor/wcl_hardcore_api.js，一般不必再手动上传。终审导出保存到 verdicts/verdict-日期.json。
