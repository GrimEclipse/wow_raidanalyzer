# v1.5 公会分析与 M7 战术轴

分析规则取自 **WCL 日志归属公会**。ID 774422（阿瓦隆）默认启用专属规则；其他公会、没有公会信息的日志使用基础分析。M5、M6、M7 的分析配置允许主动选择基础分析。不会用当前账号的默认公会替代日志归属。

- M5：阿瓦隆按战术板集合检查；基础分析按实测怒不可遏检查。
- M6：基础报告保留全部蛇头、位置和实际打断玩家。只有阿瓦隆且填写打断安排时分配主断责任；未填名单不默认给坦克归责。免疫名单和保护配对只在专属模式核对。
- M7：史诗阿瓦隆日志先判断 P1/P2 是否提前结束，再决定是否统计爆发缺失。

## 停手顺序

P1 必须完成约 2:42 的末轮撕裂，且至少打到 2:50；首次恐惧行军必须在 3:05 或之后开始读条。任一时间门槛提前都跳过爆发缺失计数；缺少首次行军读条时保留待确认。P2 采用旧史诗样本的末轮刀相对时间 202.790 秒，并按本场 P2 起点和第一刀的实际延迟校正。到 1 血/死亡优先于下一阶段标记；缺少要求刀的完成证据时保留待确认，不计漏爆发。

任何前序阶段提前都会使本场爆发缺失计数跳过。每阶段提供独立 1%–10% 滑块，默认 5%。只计玩家以该阶段 Boss 为目标的成功 `cast`；宠物施法不计，宠物与召唤物伤害逐层归属主人。没有施法但有持续伤害的玩家仍保留。血量必须来自 Boss 自身资源或此前 3 秒内的 Boss 样本，不使用未来采样或玩家血量，不把缺失当零。

入口位于整晚概览的“公会战术核对：停手与爆发轴”，可选择场次直达单场模块。已进入阶段始终显示滑块；未确认提前时仅供取证，不计停手责任。“机制统计”保留整晚汇总，其逐条记录直接跳到战术模块。旧 JSON 缺少此数据时明确提示使用 1.5 重新分析。

停手表默认按总伤害（含宠物）降序，支持按玩家本体伤害、宠物伤害、Boss 目标施法次数和姓名切换升降序；P1/P2 的排序和滑块彼此独立，调整血量阈值后保留排序。爆发轴默认展示全部 DPS，每名玩家一行并合并所有技能，未匹配安排的 DPS 保留原因；可切到全部角色。不同技能以行内颜色对应图例，要求窗口、实际施法和光环持续时间保持各自证据。“专注查看”提供完整屏幕空间，详细计数表默认折叠。本次为展示调整，已有 1.5 报告刷新后生效，无需重新查询日志。

概览阶段短标签仅显示 P1/P2/P2.5/P3。颜色与进度条取 WCL `fightPercentage` 的全程完成度：0%–25% 灰、25%–50% 绿、50%–75% 蓝、75%–95% 紫、95%–99% 橙、99% 起粉；边界左闭右开。旧多阶段报告若缺少全程进度，显示中性灰并提示重新分析，不用阶段血量冒充。共享额度改为页头下方右侧的正常文档布局。

## 爆发安排

默认安排转录自提供的截图；战士按确认的天神下凡核对。乾元之巅 1249625、时间跳跃 404977 和饰品均进入公共技能目录。主动饰品包括 1297761、1250533、1293316、1295885；神像只匹配主动效果 1295885，不匹配被动减智力叠层。

固定轴以开战计时：P2 基准 3:00、易伤期基准 6:35、P3 基准 7:10（易伤期加 35 秒）。每个阶段的窗口分别随本场阶段起点平移。P1 保持固定。默认容差为前后 10 秒（时间跳跃为前后 3 秒）；鸟德 3:00/3:20 采用明确区间。窗口未走完、未进入对应阶段、角色/专精不匹配或技能未解析都不计错。一条施法不能匹配同技能的多个窗口。技能多充能或刷新 CD 不改变“窗口内有实际使用”的要求。

默认法师安排按本场专精选技能：奥术为奥术涌动，冰霜为冰霜射线，保留该玩家既定时间点；自定义明确指定的技能不自动替换。小楚唯、贪睡熊熊在恢复专精时不核对默认 DPS 爆发或输出饰品安排，平衡专精时恢复核对。

技能施法与效果 ID 分开：奥术涌动成功施法为 365350，自身增益为 365362。持续条采用实际增益的应用/移除时间，不强制截为基础 15 秒；Fight 5 可见约 17.4 秒的实际记录。亘古吐息采用本施法者在敌方目标上的时光创伤 409560/409722，按目标及生成实例独立处理，并合并重叠的别名光环；不采用自身飞行光环。冰霜射线属于纯伤害技能，仅显示成功施法点，不补造增益条。目录的 179 个施法/原有 ID 加 3 个效果 ID 已通过 WCL GameData 校验。亘古吐息的敌方效果说明可对照 [技能资料](https://www.wowhead.com/spell=403631/breath-of-eons)。

阶段色块显示提前秒数，并区分“起点早”（相对截图固定轴）与“结束早”（相对本阶段最早结束门槛）；P1 另外显示首次恐惧行军提前量。P2/P3 继承的起点偏移不叠加到本阶段结束提前量里。旧 1.5 数据可从原阶段门槛和窗口平移量计算这些标注，但新增技能效果证据需要重新取证。

报告展示每人标记次数、每个要求窗口、上次与下次实际使用，以及提前、延后、未使用等原因。爆发条优先采用实测光环持续时间；缺少光环时保留施法点，不补造技能持续时间。转阶段的爆发药检查沿用原有存活非治疗口径。

分析前可用 `burstPlan` 替换默认安排（留空表示截图预设），例如：

```json
[
  {"player":"染小战","ability":"warrior.avatar","times":[0,180,246,331,395,565]},
  {"player":"小楚唯","spellIDs":[1295885],"label":"妖术领主的厄运神像","times":[0,[180,200],395,565]}
]
```

`times` 为开战后秒数；单个数表示时间点，两个数的数组表示允许区间。`ability` 为公共目录 key；自定义 `spellIDs` 为用户确认的准确主动技能 ID。可选 `durationSeconds` 只用于无光环时的示意，界面会标注估算。不要用装备物品 ID 代替主动技能 ID。

## 场景一致性

M7 首页推演、战斗回放与机制工作台复用 `CoiledAltarReplay`，由同一个播放时间重建球、携带、锥形、鬼、炸弹和场地污染。筛选影响证据检索，不把选中事件的旧快照覆盖到当前场景。旧报告缺少连续场景时提示重新分析，保留证据表。全局播放器不再在首个采样之前显示未来位置，不从未来事件选择场地快照，筛选也不会自动跳走当前播放时间。
