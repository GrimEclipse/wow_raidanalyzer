# GitHub 自动更新

服务每 15 分钟通过 `git ls-remote --tags origin` 检查一次稳定版本标签，不调用 WCL。
只有管理员能在首页看到提示并点击“更新并重启”。版本标签采用 `v主版本.次版本.修订号`，例如 `v2.0.1`。

更新前必须满足：当前运行在 `main` 分支、Git 工作区没有未提交或未跟踪文件、没有排队或运行中的分析任务。服务只接受比当前版本新的标签。独立更新进程等待服务器退出，执行 `git fetch --tags origin` 和 `git merge --ff-only`，随后以原监听地址和端口重启 `server.py`。失败时也会重启原版本，并将原因写入 `data/app_update.log`。

发布新版本时先将代码提交到 `main`，创建并推送相应的版本标签。仅推送分支而没有标签不会触发更新提示。此功能用于直接运行 `server.py` 的部署；由 systemd、容器或其他进程管理器托管时，应由该管理器负责重启，避免同时启动两个实例。
