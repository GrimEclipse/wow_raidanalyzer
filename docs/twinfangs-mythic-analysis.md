# 双子毒牙史诗分析

在 `/online` 选择双子毒牙。八个分析项默认启用，可分别关闭；关闭项不会当作零失误计入概览。

## 名单与判定

- 永恒毒液页和地板炸圈页新增每轮可展开的全团条状图，沿用腐蚀洪流后的现有吃球窗口（从洪流完成到下一次剧毒涌现开始，左闭右开），不按盛宴重新划轮。按吃球次数从少到多排列，包含零吃球玩家，并注明轮初 / 轮末死亡状态。黄色为吃球新增层数，橙色为异常技能实际命中次数，蓝色为其他新增层数；异常造成的层数和总新增层数另列。未知来源在其他段中单独注明，不直接认作正常来源。三段分别使用标注的层 / 次单位，整条长度不代表实际携带层数。
- 免疫分摊页新增异常时机使用保护、无敌、冰箱、龟壳的明细，包括施法者、实际目标、结束时间、后续安排与名单外免疫参与者。施法与光环应用合并为一次使用；非盛宴时段或免疫结束后未覆盖已安排伤害段标记待复核，补位成功仍保留。盛宴前 10 秒至第三段附近作为准备窗口，窗口外实际覆盖盛宴的使用不标异常；缺少光环或伤害段证据时不强判。该记录不证明误操作、冷却不足或补位的因果关系，不追加个人分摊失误。旧分析结果需要重新分析才能获得新增字段。
- 盛宴默认免疫打法，每一轮填四个玩家名或本报告 Actor ID，不限制职业（包括接受保护的玩家）；一轮是一次完整三段攻击，首段全团，后两段核对名单。表内只展示安排玩家和实际免疫补位者。当前支持四轮安排，不擅自循环第五轮。
- 每轮保护配对依次填施法者、受保护玩家，可重复填写多对，不限制受保护者职业。首段击飞前没有保护或后续保护未覆盖，归到施法者，并展示其实际保护目标；只有预先获得保护并持续覆盖的玩家未参与，才归到该玩家。其他玩家成功补位完成四人免疫分摊时，不按原名单缺席计错。每人每轮最多一次。
- 免疫命中、偏转与零伤害需要结合命中类型和光环证据。免疫提前结束直接计入失败，但日志不证明具体按键操作。缺失整段数据、名单无法匹配时不凭空归责。
- 蛇头每轮每侧分别计近战组和远程组出现序号。点位 1/2 由当前该侧 Boss 坦克负责，近战补断；远点按第一、第二、第三个出现分配远程，第四个及以后交补断。每场只返回第一次成功施法，时间取施法完成时间，序号保留此前该组蛇头的出现顺序；后续漏断全部忽略。结论按“左侧远程组第4个蛇头漏断脏腑爆裂”展示，不生成个人漏断排行榜。
- 裂石击一次全团爆发计一次，展示实际接圈坦克；没有直接目标时注明同组三连击目标或当前仇恨推断，证据不足显示未知。从本场首次坦克死亡起停止统计，战复后也不恢复本场计数；非坦克不作为接圈责任人。
- 整晚分摊明细直接显示玩家、轮次、伤害段和未参与/未正确免疫的原因。首漏断默认按左前/左后/右前/右后第几断统计（前为近点，后为远点），可切换至归责玩家并使用职业颜色；归责玩家不考虑补断。近点两次均取漏断结算前当前该侧 Boss 坦克。首漏断前已有至少三人死亡且未战复时，整场漏断豁免。带毒死亡仅保留单场明细。
- 提前死亡按死亡序列的首个明显间隔划分，默认 8 秒，可配置；保留全部死亡前 8 秒伤害，不将“提前死亡”直接当作个人失误。
- 带毒死亡层数是额外球的机制预期数量，实际球爆炸另行统计。时间相邻不等于唯一来源关系。
