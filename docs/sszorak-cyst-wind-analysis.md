## 判定规则

- 囊肿按每轮两批点名、每批两名目标记录。史诗插件已经固定分配位置，不再要求第四名玩家为缺失风向补位；第四人保留位置、激活和风向证据，但不因未补足判错。
- 前两人的放置已有明确偏差时，第三人可能在补位，不再追加“未补足”责任。前两人没有偏差时，第三人的原覆盖检查保留。没有插件分配证据时，不臆测个人补位职责。英雄难度保留原有覆盖规则。
- 吹风依据可靠坐标中的同步位移推断，优先比较每个方向人数最多的两帧，再比较峰值人数和持续帧数，避免少数人长时间斜向走位压过团体短时间同步受风。
- 囊肿激活前100ms及后2500ms不参与方向投票。前窗为200ms采样的一半，保留临近激活前最后一个完整的团风样本；不根据囊肿摆放位置反推风向。
- 三段风固定分割25秒掘地窗口。战斗提前结束时不把三段压缩到已记录时间，也不外推战斗结束后的玩家移动。
