更新日志以及相关碎碎念

当前版本 v1.3.2

  1. v1.3.2 M5 斯索拉克与乌拉特克复盘更新

    • M5 斯索拉克补齐史诗毒蛇之怒、四向侧风，以及风暴施加/刷新和主动驱散归属。
    • 乌拉特克新增固定左右场拉线批次、毒蛇之咬实际分摊、P1/P3 吃波死亡与盘绕猎物死亡统计。
    • P3 蛋会排除固定尖啸者；额外孵化时返回漏蛋的玩家转火伤害。拉线每场只归责首个违规者。

  2. v1.3.1 陵寝哨兵史诗复盘与输入优化

    • 陵寝哨兵史诗难度新增变幻的原型毒液碰撞与队友击飞归因。
    • 史诗放水改按横排直线检查，并修复“团队内第一个撞错”的玩家汇总。
    • 乌拉特克英雄难度攫取毒牙允许三层拉断，报告输入支持完整 WCL 链接。

  3. v1.3.0 快速分析与本地报告工作流更新

    • 首页新增“一键分析最新一场 Boss”，自动使用账号默认公会定位最新 Report 的最后一场战斗。
    • 公会信息改为账号级配置，支持多个公会、默认公会和下拉选择。
    • 本地 JSON 成为正式报告入口，文件留在浏览器本地数据库；服务器结果与单场缓存加入容量和过期清理。
    • 首页与账号设置换上新视觉，并保留低动态模式。
    • 首页趣味台词每次进入时随机抽取一次，实验入口仅管理员可见，高级单场选择移到快速开始区域。
    • 尼姆瑞莎·唤潮者已接入基础战斗复盘，不再因缺少分析插件中止最新战斗流程。
    • 账号页加入 WCL V2 Client 完整图文指引；乌拉特克蛇母之怒 A 团会显示当轮承接目标。

  4. v1.2.0 烈毒之渊团本分析更新

    • 为所有boss统一增加死亡原因、致死技能与战复时间线；整场概览按普通、英雄和史诗难度分组。
    • 为烈毒之渊所有的boss都调整并支持了单场统计/整场战斗关键机制数据分析
    • 目前史诗难度仅支持盘魂者和迷失的冒险者。更多的史诗难度boss正在随着开荒进度添加中。
    • 大秘境的相关功能将会在团队副本稳定后进行更新，目前国家队也没确定，暂时搁置一下。

      • 单专精战斗复盘需要庞大的数据和要求支持。这个功能是化肥最先想让我帮忙分析奶骑使用的。如果这个功能有持续更新的想法需要各专精大佬的支持。

  5. v1.1.0 正式服资料与陵寝哨兵分析更新

    • 新增所有 Boss 共用的整场 Pull 概览：按阶段归类灭团、显示进度与时间，并从 Pull 方块进入对应 Boss 的单场分析。
    • 新增陵寝哨兵专项复盘：螺旋毒素碰撞链、酸液/鲜血印记、分摊参与、附着幽暗离散、活体毒液与剧毒水滴分析。
    • 螺旋毒素支持同帧多条安全移除的两两归组；安全碰撞同样保留时间戳、玩家 ID 与证据来源，只有真正缺失搭档时才使用坐标补配。
    • 团本资料切换到正式服 WCL Zone 53 与正式 encounter ID，并更新团本手册、普通难度证据、团队排轴和通天峰分析样例。
    • 服务端支持可配置监听地址与端口；本地代理证书提示只在确认是回环代理时收敛，远程 TLS 风险仍保留警告。

  6. 爬爬想把这个系统作为一个能便利于 Avalon 公会使用的快捷查询工具，包括 Boss 的技能介绍、开荒日志检查、大米极限层抄轴、团本根据同治疗组来快速产生战术板、单场断案，以及用于课代表记录每次开荒的拾取记录等功能。

    人总会有失误，把自己曾经犯过的错误留下“案底”实在压力太大，所以我单方面取消掉了智商记录本的功能，同时这个功能也不利于迁移……我只会判断出每天日志中导致灭团的原因是什么，来快速帮助团长等定位这些问题。说白了也只是自己的一己私愿，不过初心绝对只是单纯地为了快速辅助团队通过副本和高难度 Boss，而不是为了“开庭”队友们。当然如果之后智商团能够复用到，我会单独外接一个定制化需求的版本，也算是自己给自己练手。

  7. 目前系统已经维护的内容基本都可以使用，并且基本都外接了 Wowhead、lorrgs.io 等工具的附件。只要你能访问到这个网站，你基本都可以无痛访问到 Wowhead 上的相关资源。

    有相关需求的可以直接反馈给我，或者提交 GitHub Issue。我会在能力范围之内快速处理这些需求。
