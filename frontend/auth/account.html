WCL V2 Client

获取 Client 凭据

先关联 Battle.net 账号，再创建一个非 Public 的 V2 Client。

  1. 登录 WCL 并进入设置。
  2. 关联一个 Battle.net 账号。
  3. 进入 V2 Client 管理页。
  4. 创建非 Public Client。
  5. 立即保存 ID 与 Secret。
Client Secret 不是 WCL 登录密码，也只会显示一次。请勿向其他人发送凭据。

WCL V2 Client 完整图文指引（5 步）

点击截图可查看原图。界面文字可能随 WCL 更新略有变化，但入口与填写原则一致。

第 1 步：登录 WCL，打开账号设置

进入 Warcraft Logs 并登录。点击右上角账号菜单中的 Settings。

第 2 步：关联 Battle.net 账号

在设置页找到 Battle.net Account。WCL 要求账号至少关联一个 Battle.net 账号后才能创建 V2 API Client；关联成功后页面会显示已绑定的 BattleTag。

目前国服登录可能无法直接完成关联，建议选择 Asia 并关联一个亚服 Battle.net 账号。

第 3 步：进入 V2 Client 管理页

继续在设置页找到 Web API，点击 manage your V2 clients here。

第 4 步：创建 Client

点击右上角 Create，填写便于识别且不与其他应用重复的名称和 Redirect URL。若名称重复，换一个名称即可。

不要勾选 Public Client。确认后点击 Create。

第 5 步：立即复制并保存凭据

创建成功后，绿色提示框会显示 Client ID 与 Client Secret。复制到本页上方的凭据表单并保存，然后点击“测试 API”。

Client Secret 只显示这一次；如果遗失，只能删除原 Client 后重新创建。
