Offline Package

WoW Raid Analyzer

纯静态可用：内嵌复盘数据 + 浏览器直接导出终审 Excel（无需 Python）。

Report

主报告 / 开庭 / 终审

报告入口只加载对应 Boss 的专属页面；尚未完成专属页面的 Boss 会明确显示不支持。

Fight Audit

奥蕾莉亚逐场场地分析

按 Fight、阶段和 Tag 定位场地快照。

Roster

下版本职业初筛

选择主职与次选专精，查看团队职责、近远程与职业覆盖情况。离线填写保存在当前设备。

用法：双击 start_offline.bat 或打开本页。Excel 由 assets/vendor/verdict-xlsx.js 前端生成，file:// 与本地服务均可导出。
