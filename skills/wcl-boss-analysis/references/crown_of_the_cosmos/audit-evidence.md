# 奥蕾莉亚审查证据链草案

本文档定义 `crown_of_the_cosmos` 后续全量审查输出的数据口径。目标是让每条结论都能回到 WCL 事件、时间戳、玩家、坐标或链接，而不是只给一个扣分结果。

## 通用基础

- 战斗范围：对同一个 report 内所有 `Crown of the Cosmos / Alleria` fight 全量分析，不只分析灭团战斗。
- 首页第一屏：按 fight 输出灭团阶段、关键死亡原因、fight 时长、是否击杀、WCL 链接。
- 职责分类：使用 `boss_plugins.common.build_player_mechanic_roles()`，输出 `tank / melee-dps / melee-healer / range-dps / range-healer`。
- 坐标证据：优先读取带 `includeResources` 的事件字段 `x / y / facing / mapID`，坐标按 WCL 原始值保留，同时提供 `/100` 后的战斗坐标。
- 置信度：坐标或朝向来自机制时间点前后 0.5 秒内为 high，1.5 秒内为 medium，超过 1.5 秒或缺失为 low / unknown。
- 可审查链接：每条明细都保留 `reportID / fightID / timestamp / abilityID / sourceID / targetID / wclDeepLink / replayLink`。

## 全局统计

### 0. 灭团阶段区分

证据：`Deaths`、关键 `Buffs/Debuffs/Casts/DamageDone`、阶段 marker。

判定：沿用现有 `classify_fight()`，输出 `P1 / P1.5 / P2 / P2.5 / P3 / kill / unknown`，并给出触发判定的首个死亡、关键技能或阶段 marker。

输出：fight 卡片列表，第一屏展示。每张卡包含阶段、原因、死亡玩家、时间点、WCL 死亡页链接。

### 1. 全局放水过偏检查

证据：`1283236 虚空斥力 debuff`、`1233819 虚空斥力 cast`、机制前后坐标资源事件。

判定：每一轮以同组 debuff 或 boss cast 作为 anchor，计算被点名玩家放水点与该轮推荐集合中心/团队约定中心的偏离。偏离超过 8 码记为过偏。

输出：按 fight 和玩家汇总过偏次数；明细包括时间、玩家、坐标、偏离距离、地图点位。

### 2. 崩裂空无误伤总和

证据：`1255378 崩裂空无 DamageDone`、`1260027 空虚之握 Debuffs`、玩家坐标。

判定：保留现有误伤归因；新增射击路线和受害者坐标。若射线和实际命中不一致，标记为低置信复核项。

输出：误伤来源玩家排名；明细展示射击玩家、被误伤玩家、时间、射线、双方坐标。

### 3. 死于空虚之握前 6 秒治疗

证据：`Deaths` 中死亡技能为 `1260027` 或可归因到空虚之握；死亡前 6000ms 的 `Healing` 事件。

判定：统计 healer 对死亡玩家造成的有效治疗量，healer 来自职责分类中的 `melee-healer / range-healer`。

输出：外层按死亡玩家和治疗玩家汇总；明细可展开到 fight、死亡时间、治疗技能、治疗量、过量和吸收。

## P1 统计

### 1. 腐化精华命中次数

证据：`1261531 腐化精华` 的 hit / apply 事件。

判定：按玩家累计被命中次数。

输出：列表排名，不展示 details 柱状图。

### 2. 死于银锋箭且伤害高于 300000

证据：`Deaths`、`1233649 银锋箭` 伤害事件。

判定：死亡事件或死亡前最后伤害包含银锋箭，且承受伤害 `amount + absorbed >= 300000`，标记疑似未开减伤。

输出：玩家、时间、伤害量、吸收量、死亡前减伤证据缺口。

### 3. 银锋箭误伤统计

证据：`1233602 银锋箭标记`、`1233649 银锋箭` 伤害。

判定：以点名玩家为来源归因，统计其本轮银锋箭命中的非目标玩家数量。

输出：点名玩家排名；明细列出被误伤玩家、时间、伤害、WCL 链接。

### 4. 空虚之握死亡前 6 秒治疗

同全局统计第 3 项，但阶段过滤为 P1。

### 5. 银锋箭应瞄准 Boss 统计

证据：P1 全 6 轮银锋箭标记、目标 Boss 或 add 的坐标、银锋箭命中事件。

判定：每一轮取点名 A/B、应射击 Boss 坐标和实际命中目标。若命中 Boss，则记录 `A/B 的银锋箭命中了 Boss {name}`；若未命中，记录失败原因和命中对象。

输出：P1 六轮全量列表，不只在灭团时输出。

### 6. P1 Boss 倒 T

证据：死亡人数、坦克死亡事件、`1 近战攻击` 或坦克技能死亡、`1233778 回响虚空` 层数、战斗时间。

判定：死亡人数小于 3，坦克被近战或坦克技能致死，且当前战斗时间小于 2:20，则返回回响虚空层数。

输出：坦克、死亡时间、致死技能、回响虚空层数、死亡前 6 秒治疗和减伤。

## P1.5 统计

### 1. 阶段死亡次数

证据：阶段 marker 和 `Deaths`。

判定：死亡时间落在 P1.5 区间。

输出：按玩家累计死亡次数，明细给出致死技能和时间。

## P2 统计

### 1. P2 放水过偏

同全局放水检查，但阶段过滤为 P2。

### 2. 虚空斥力 cast 时远程过于离散

证据：`1233819 虚空斥力 Casts`、远程职业坐标。

判定：boss cast 时间点，统计 `range-dps / range-healer` 坐标离散程度；离团队远程集合中心超过阈值的玩家记为离散。

输出：玩家、次数、cast 时间、坐标、距离。

### 3. 虚空斥力 debuff 消失时点名玩家过于离散

证据：`1283236` removedebuff、被点名玩家坐标。

判定：同轮点名玩家在 debuff 消失时坐标之间距离过大，或单人偏离集合中心超过阈值。

输出：轮次、玩家、坐标、离散距离。

### 4. 银色幻影射击失败

证据：`1260027 空虚之握` apply/remove、玩家 `x/y/facing`、`1255378 崩裂空无`、银色幻影存活状态和坐标。

判定：以点名时玩家面向预测三条射线；在 debuff 消失后的窗口内检查是否命中存活银色幻影。未命中且幻影仍存活，记录失败点名玩家。

输出：每轮点名玩家、三条射线、幻影坐标、实际命中、失败原因、置信度。

### 5. 银锋弹射消除 Boss 能量失败

证据：`1259861 游侠队长印记`、`1259869 银锋弹射`、`1259998` 能量扣除事件、boss 能量资源。

判定：每轮点名后没有产生对应的 boss 能量减少，或能量减少不足，记录点名玩家。

输出：点名玩家、轮次、boss 能量前后、是否失败、WCL 链接。

## P2.5 统计

### 1. 宇宙屏障后 5 秒击飞死亡

证据：`1261289 宇宙屏障 Casts`、`Deaths`、坠落技能 `3`。

判定：宇宙屏障 cast 成功后 5000ms 内死于坠落，记为击飞死亡。

输出：玩家、死亡时间、相对屏障时间、WCL 链接。

### 2. 死于次元斩

证据：`1260838 / 1260839 次元斩` 死亡或伤害事件。

判定：死亡事件致死技能为次元斩，或死亡前最后伤害为次元斩。

输出：玩家次数和明细。

## P3 统计

### 1. 重力坍缩大规模死亡

证据：现有重力坍缩逻辑、`1255453` debuff、`1239095` 伤害/死亡。

判定：保留现有逻辑，输出 3 个被点名玩家，并返回拉断导致血崩的玩家。

输出：点名玩家、拉断玩家、死亡链、WCL 链接。

### 2. 宇宙传送门时玩家站位

证据：`1260766 / 1260771 宇宙辐射`、`1261339 宇宙传送门 Casts`、P3 大怪/裂隙幻影狂暴事件。

判定：P3 中不固定用宇宙辐射结束作为唯一锚点；当出现 `1261339` cast 或大怪/裂隙幻影获得狂暴时，抓取该时间戳全团坐标。

输出：cast 时间、全团坐标快照、replay link。若发生狂暴，附带狂暴来源和时间。

### 3. P3 坠落死亡

证据：P3 阶段 `Deaths`，技能 `3 坠落` 或环境死亡。

判定：死亡时间落在 P3，致死技能为坠落/环境。

输出：玩家次数和明细。跳楼类特殊情况暂不单独处理。
