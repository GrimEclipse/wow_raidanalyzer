Update notice

更新日志

v1.4.0 · 页面与登录体验

  • 首页改用低对比度的 Canvas 环境光点，不再显示大星体。
  • 登录与注册改为弹窗，访问需登录的功能后继续前往原页面。
  • 开放首页与团长手册，普通账户可使用自己的 WCL 凭据运行分析。

v1.3.2 · M5 斯索拉克与乌拉特克复盘更新

  • M5 斯索拉克补齐史诗毒蛇之怒、四向侧风，以及风暴施加/刷新和主动驱散归属。
  • 乌拉特克新增固定左右场拉线批次、毒蛇之咬实际分摊、P1/P3 吃波死亡与盘绕猎物死亡统计。
  • P3 蛋会排除固定尖啸者；额外孵化时返回漏蛋的玩家转火伤害。拉线每场只归责首个违规者。

v1.3.1 · 陵寝哨兵史诗复盘与输入优化

  • 陵寝哨兵史诗难度新增变幻的原型毒液碰撞与队友击飞归因。
  • 史诗放水改按横排直线检查，并修复“团队内第一个撞错”的玩家汇总。
  • 乌拉特克英雄难度攫取毒牙允许三层拉断，报告输入支持完整 WCL 链接。

v1.3.0 · 快速分析与本地报告工作流

  • 默认工会可以一键定位最新 Report 的最后一场 Boss 战，高级选择仍保留独立入口。
  • 工会与 WCL 凭据改为账号级配置；账号页提供完整的 V2 Client 五步截图指引。
  • 本地 JSON 直接保存在浏览器本地数据库，服务器临时结果和单场缓存加入容量与过期清理。
  • 首页切换为深空视觉与随机趣味台词，实验功能仅管理员可见。
  • 尼姆瑞莎·唤潮者已接入基础复盘；乌拉特克蛇母之怒 A 团会显示当轮承接目标及证据。

v1.2.0 · 烈毒之渊分析

  • 烈毒之渊 Boss 增加死亡、战复和专项机制分析，整场概览按难度分组。
  • 团本资料迁移到正式服 WCL Zone 53，并补充正式技能与样本证据。

v1.1.0 · 整场概览与陵寝哨兵

  • 新增所有 Boss 共用的整场 Pull 概览，以及陵寝哨兵螺旋毒素、分摊和场地机制复盘。
